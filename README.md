# Games for Teddy & Tommy 🎮

**▶ Dashboard: https://adong.github.io/games-for-teddy-tommy/**

Browser games starring two brothers: Teddy, with his boxing combos and basketball jump shot, and Tommy, with his ✌️ Y pose. Every game has a companion mode where you call the other brother in to help. They all play on phones, tablets and computers, with nothing to install. In any game, press **?** (or tap the round **?** button on the left edge) to see its keys; the game waits while you look.

## How they're made

Every game is plain JavaScript on Three.js and ships as one HTML page. The characters, their poses and the sound come from a shared kit, so Teddy and Tommy look and move the same in every game. Built by Dad with [Claude Code](https://claude.com/claude-code).

To add a game here, move it from `SOON` to `LIVE` in `index.html`, save its title-screen screenshot as `shots/<repo>.jpg`, and add a row to the table above.
